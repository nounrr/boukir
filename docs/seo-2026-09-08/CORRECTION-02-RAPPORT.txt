COOKIES ET API
Le code de connexion définit accessToken HttpOnly, Secure en production,
SameSite=Lax, Path=/, sans Domain : cookie limité à l'hôte. Le cookie public
NEXT_LOCALE observé est aussi limité à l'hôte, Path=/, SameSite=Lax.
Ne pas élargir Domain à tous les sous-domaines. Une ancienne session www peut
nécessiter une nouvelle connexion sur apex ; le panier anonyme localStorage
est également propre à l'origine. Aucune migration de stockage www n'est faite.
Le parcours testé est anonyme : aucune session authentifiée n'a été créée.
L'API cliente utilise Authorization si connecté et les en-têtes Content-Type
et Platform. Le middleware cors existant est avant l'authentification et répond
aux OPTIONS ; il reflète les en-têtes demandés et ajoute Vary: Origin.
Le proxy doit transmettre Origin et les Access-Control-Request-* sans interception.
